## 💻 로컬 실행 (uv)

[`uv`](https://docs.astral.sh/uv/)로 Python 3.12 환경을 만들고 노트북을 실행/검증할 수 있어요.

> 📌 학생 실행 환경(Google Colab)과 동일하게 **pandas 2.2.2 · numpy 2.0.2** 로 고정돼 있어요 (`pyproject.toml`).

```bash
# 1) 환경 구성 (.venv + uv.lock 생성, 의존성 설치)
uv sync

# 2) Jupyter 커널 등록 (Jupyter/VS Code의 커널 목록에 "incheon-data (uv)" 추가)
uv run python -m ipykernel install --user --name incheon-data --display-name "incheon-data (uv)"

# 3) Jupyter Lab 실행 → 커널을 "incheon-data (uv)"로 선택
uv run jupyter lab
```

### 노트북 자동 검증

모든 노트북을 위에서부터 끝까지 실행해 통과/실패를 한눈에 확인:

```bash
uv run python scripts/validate_notebooks.py            # 전체
```

- ⚠️ **데이터없음** — 외부 CSV가 필요한 모듈(M01·M02·M04~M11 등)은 `data/README.md` 안내대로
  CSV를 받아 **저장소 루트**에 두면 그때 ✅로 바뀝니다.
- ❌ **오류** — 진짜 실행 오류. (있으면 스크립트가 비0 코드로 종료)
