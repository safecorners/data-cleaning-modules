## 파일별 상세

### 1. `경찰청_범죄 발생 지역별 통계.csv` (cp949) — M01 메인 예제
- **받는 곳**: [공공데이터포털 data.go.kr](https://www.data.go.kr/data/3074462/fileData.do) → "경찰청_범죄 발생 지역별 통계" (경찰청, 파일데이터).
- **구조**: 38행 × 249열. **행 = 범죄 유형**(`범죄대분류` 15종 · `범죄중분류`), **열 = 지역**(`서울 종로구` … `외국 기타국가` 등 시도 시군구 단위 247개). 값은 발생 건수.
- **모듈에서 읽는 법**:
  ```python
  df = pd.read_csv('경찰청_범죄 발생 지역별 통계.csv', encoding='cp949')   # utf-8 기본값으로 읽으면 UnicodeDecodeError
  df.head()
  ```
- **함정**:
  - ① **인코딩**: 옵션 없이 읽으면 `UnicodeDecodeError` → `encoding='cp949'` (M01의 핵심 사례).
  - ② **가로형(wide)**: 지역이 열로 펼쳐져 있어, 지역별로 분석하려면 전치(`.T`, → M11)하거나 `범죄대분류`·`범죄중분류`를 멀티인덱스로(`set_index([...])`, → M07) 잡아야 함.

### 2. `스트레스_인지율.csv` · `우울감_경험률.csv` (KOSIS, utf-8)
- **받는 곳**: [KOSIS 국가통계포털 (해당 통계목록)](https://kosis.kr/statisticsList/statisticsListIndex.do?menuId=M_01_01&vwcd=MT_ZTITLE&parmTabId=M_01_01&parentId=F.1;F_55.2;117_11758_011.3;&outLink=Y#117_11758_011.3) → 목록에서 "스트레스 인지율" / "우울감 경험률" 선택 → 행렬(시도×성별×연령) 형태로 다운로드.
- **구조**: 헤더가 3~4행에 걸친 **다층(멀티) 헤더**. 첫 열이 지역(시도).
- **모듈에서 읽는 법**:
  ```python
  df = pd.read_csv('스트레스_인지율.csv', header=[0, 1, 2, 3], index_col=0)   # 방법 A
  df['전체']['인지율']['남학생']   # 멀티인덱스 접근 예
  ```
- **함정**: 헤더 행 수를 잘못 세면 데이터 첫 줄이 헤더로 들어감. raw CSV를 head 5줄로 먼저 확인. (→ M07 7.1)

### 3. `인천광역시_인구추이_현황_20231231.csv` (cp949)

- **구조**: 연도가 열, 항목(`인구추이별(1)`, `인구추이별(2)`)이 행 → **행/열이 뒤집힌** 형태.

### 5. `한국교육개발원_시도 시군구별 졸업자 진학자 진학률_20240401.csv` (cp949) — *합성*
- **받는 곳**: [공공데이터포털 data.go.kr (해당 파일)](https://www.data.go.kr/data/15053808/fileData.do).
- **핵심 컬럼**(모듈이 기대): `시도`, `졸업자`, `진학자` (시군구 단위 행)
- **모듈에서 읽는 법**:
  ```python

  graduate.groupby('시도')[['졸업자', '진학자']].sum()   # 시도별 집계 (→ M09/M10)
  ```

### 6. `교육부_지방교육재정정보_순계_2024.csv` (cp949) — *합성*
- **받는 곳**: [공공데이터포털(메타)](https://www.data.go.kr/data/15052877/fileData.do) → [지방교육재정알리미](https://www.eduinfo.go.kr/portal/open/openData/dataSetPage.do) → **예산통합공시 > 재정규모 > 통합재정 > 순계**.
- **핵심 컬럼**(모듈이 기대): `시도`, (예산/재정 금액 컬럼)
- **⚠️ 핵심 함정**: `시도` 값 앞에 **공백 한 칸**이 붙어 있어(`' 서울'`) 그대로 merge하면 매칭이 안 됨.
  ```python
  budget['시도'].unique()        # ' 서울' 처럼 앞 공백 확인
  budget['시도'] = budget['시도'].str.strip()   # merge 전에 반드시! (→ M08 핵심 사례)
  ```

### 7. `OBS_ASOS_TIM.csv` (cp949) — M02 결측치 메인 예제
- **받는 곳**: [기상자료개방포털 — 종관기상관측(ASOS) 자료](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36) → **자료형태 `시간 자료`**, 지점 **인천**, 요소 `기온·강수량·풍속·습도` 선택 → CSV 다운로드. (비회원은 시간자료 24건까지 → 24행)
- **핵심 컬럼**: `지점`, `지점명`, `일시`, `기온(°C)`, `강수량(mm)`, `풍속(m/s)`, `습도(%)`
- **⚠️ 핵심 함정(자연 결측)**: `강수량(mm)`은 비가 안 온 시간대엔 빈 값(`NaN`). 받은 기간이 전부 무강수면 **그 컬럼 전체가 NaN** → `dropna()`(axis=0)는 전 행을 지우니 `dropna(axis=1)`로 컬럼을 떨궈야 함. (→ M02 핵심 사례)
  ```python
  weather = pd.read_csv('data/OBS_ASOS_TIM.csv', encoding='cp949')
  weather.isnull().sum()       # 강수량(mm)만 결측 (24개)
  weather.dropna(axis=1)       # 강수량 컬럼 제거 → (24, 6)
  ```
